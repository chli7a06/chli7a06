# واجهة ما كتبانش / الماوس محبوس

- دابا: F8 → mdtclose باش تطلق الماوس.
- وقف crimson_doj. حل repair ZIP وانسخ محتوى crimson_doj فوق resource الحالي مع remplacement. ما تمسحش المجلد كامل: pack ما فيهش config.lua ولا permissions.lua ولا penal_code.lua ولا أصواتك ولا recordings.
- فـconsole: restart crimson_doj.
- جرّب /dojmdt. إلا الواجهة ما تحلّاتش، الماوس كيتطلق بعد 8 ثواني وF8 كيعطي UI initialization failed أو UI did not acknowledge opening. صيفط الخطأ كامل من F8 مباشرة.

هاد النسخة فيها POST الصحيح وملفات UI كاملة باش نتفاداو ملفات ناقصة/مختلفة. السبب الخاص بالفشل الأخير ما تأكدش بلا F8؛ هادي حماية وتشخيص وإصلاح لتناسق الملفات، ماشي تغيير للصلاحيات. ما خاص لا SQL لا items جداد.
