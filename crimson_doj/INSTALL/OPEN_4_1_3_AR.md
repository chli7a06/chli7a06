# طريقة فتح الواجهة 4.1.3

قارنّا الملفات الستة اللي صيفطتي (fxmanifest/index/app/ui_health/client/i18n) مع 4.1.2: كلها مطابقة. ما تأكدش السبب الخاص بالسيرفر من هاد الملفات؛ ما غاديش نعتابروه خطأ تركيب بلا دليل.

4.1.3 كتضيف:
- Lua كيحتافظ بطلب الفتح اللي سبق للسيرفر سمح به. الواجهة كتقدر تسترجعو محلياً حتى إلا ضاع SendNUIMessage أثناء التحميل.
- الماوس ما كيتشدش حتى الواجهة تأكد أنها عرضات MDT أو الوثيقة. إلا فشل التحميل، الحماية ديال 8 ثواني كتبقى كتوقف المحاولة.
- polling محلي بين NUI وclient، ما كيديرش query إضافي فـdatabase وما كيمنحش job أو permission.
- F8 فيه client UI bridge 4.1.3 loaded وbrowser UI bridge 4.1.3 loaded. إلا بقا timeout، كيبين واش browser poll وصل وواش appReady صحيح.

## التركيب على 4.1.2

حل crimson_doj_open_fix_4.1.3.zip. انسخ الملفات الأربعة فوق نفس المسارات الموجودة ووافق على remplacement. ما تمسحش فولدر crimson_doj كامل. ما فيهش config ولا permissions ولا أصوات ولا SQL ولا items؛ ما خاصك تبدلهمش.

فـconsole السيرفر: restart crimson_doj، ومن بعد داخل اللعبة: F8 → dojmdt. إلا بقات ما كتبانش صيفط F8 مباشرة، خصوصاً الأسطر اللي فيها bridge 4.1.3 وUI did not acknowledge opening أوUI initialization failed. ما تعاودش ترسل نفس ملفات4.1.2 بلا داعي.

دوزات اختبارات الصلاحيات والواجهة، ومعاها تجربة page جديدة بالفرنسية كتسترجع طلب فتح ضائع وتجربة script ناقص كيصدر تقرير واضح. هادي تجارب development، ماشي إثبات لتشغيل FiveM فالسيرفر ديالك. ما تزادت لا مدة timeout لا تجاوز للصلاحيات.
