# Bodycam: native first person, up to one hour
التسجيل كيستعمل first person الأصلية ديال GTA على رجليك وفالسيارة. ملي كيسالي أو كيفشل، كترجع vue السابقة. المنظور كيتبدل حتى عند اللاعب لأن screencapture كيسجل نفس الصورة.
المدة 3600 ثانية (ساعة)، ويمكن توقف قبل بزر Stop recording. الحد الأقصى لكل فيديو512MiB؛ فيديو فوق الحد كيترفض. الفيديو الطويل يحتاج مساحة فالقرص ووقت للتحميل، والحد الحالي200clip. ماختبرناش ساعة كاملة داخلFiveM؛ الاختبارات هنا محاكاة.
وقف السيرفر وخذ نسخة احتياطية، ثم نسخ الملفات ديال patch إلى crimson_doj مع الحفاظ على المسارات. إلا عندك config.lua مخصص، خلي config ديالك وبدل فقط Config.Bodycam.duration = 3600 وConfig.Bodycam.maxBytes = 536870912. رجع شعل السيرفر وجرب تسجيل جديد. التسجيلات القديمة ماغاديش يتبدلو.
Config.Bodycam.view = 'gameplay' كيبقى اختيار للمنظور العادي. إعداد fov القديم ديال chest مابقاش مستعمل.
