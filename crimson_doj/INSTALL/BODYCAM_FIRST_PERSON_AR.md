# Bodycam first person
التسجيل كيستعمل دابا first person الأصلية ديال GTA، على رجليك وفالسيارة، بلا script camera من الصدر. ملي كيسالي أو كيفشل التسجيل، كترجع vue السابقة.
بدل client_bodycam.lua بهاد النسخة ثم restart crimson_doj (هاد التصحيح ماكيبدلش manifest). وقف أي تسجيل قبل restart. جرّب فيديو جديد؛ التسجيلات القديمة ماغاديش يتبدلو.
Config.Bodycam.view = 'gameplay' كيبقى اختيار للمنظور العادي. إعداد fov القديم ديال chest مابقاش مستعمل.
المنظور كيتبدل حتى عند اللاعب أثناء التسجيل حيث screencapture كيسجل نفس الصورة. التحقق هنا باختبارات محاكاة؛ خاص تجربة داخل FiveM.
